# Marketplace Pass 6: retired publication architecture

The Pass 6 GitHub dispatch, repository catalog mutation, build, and commit path was retired by Operation Severance. It is no longer an operational publication procedure. Owner and Creator publication requests return a temporary-unavailability response until Cloudflare Workers, D1, and R2 provide the replacement.

The independent Creator review, file validation, metadata mapping, D1 audit, checkout, entitlement, and delivery logic remains in place. See [Operation Severance: Task 2 handoff](OPERATION-SEVERANCE-TASK-2-HANDOFF.md) for the remaining generated-catalog dependencies and reconstruction scope.
