How to use this

  1. Fill in the required product metadata and the exact R2 folder name you want to publish into.
  2. Choose the three required files using their real final names: cover.webp, preview.webp, and product.pdf.
  3. Use the generated metadata preview below as a final sanity check.
  4. Click Publish. The page uploads to R2 first and only reports success after the GitHub build path finishes cleanly.
