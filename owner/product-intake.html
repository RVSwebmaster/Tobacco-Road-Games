How to use this

  1. Fill in the required product metadata and the exact R2 folder name you want to publish into.
  2. For a new listing, choose the three required files: one cover WebP, one preview WebP, and the product PDF. For an existing listing, leave file inputs blank to keep the current assets or add only the replacements you want.
  3. Use Check to validate missing or invalid information, then use Review to inspect the generated metadata and asset plan.
  4. Use Publish or Update only after the review looks right. The page uploads to R2 first and only reports success after the GitHub build path finishes cleanly.
